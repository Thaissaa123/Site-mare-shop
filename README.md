## 🛍️ Sobre o projeto

A **Maré Shop** é uma aplicação web desenvolvida para uma loja de moda feminina.

O projeto foi criado com o objetivo de apresentar os produtos da loja de forma organizada e facilitar o contato entre clientes e a loja.

A aplicação possui uma área para clientes e um painel administrativo para gerenciamento dos produtos, imagens, categorias e carrossel.

---

## ✨ Funcionalidades

### 🛒 Área do cliente

- Visualização dos produtos
- Busca de produtos
- Categorias e subcategorias
- Produtos organizados por diferentes categorias
- Seleção de tamanhos
- Seleção de cores
- Múltiplas fotos para cada cor
- Troca de imagem ao selecionar uma cor
- Rotação automática das fotos dos produtos
- Carrinho de compras
- Envio do pedido pelo WhatsApp
- Layout responsivo para computador e celular

### 🔐 Área administrativa

- Login administrativo
- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Cadastro de tamanhos e cores
- Upload de imagens
- Gerenciamento das fotos dos produtos
- Associação de produtos a múltiplas categorias
- Gerenciamento do carrossel da página inicial

### Coleção Inverno
